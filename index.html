이거 뽑으면 얼마? 3D 프린팅 출력 비용 계산기

이번 출력

슬라이스 파일을 올리면 사용량(g)과 출력 시간이 자동으로 채워져요. 직접 넣어도 돼요.

.gcode · .gcode.3mf — 여기로 끌어다 놓아도 돼요. 파일은 이 브라우저 안에서만 읽고 어디에도 올리지 않아요.
파일은 어떻게 저장하나요?
  1. 모델을 불러온 뒤 오른쪽 위 ‘플레이트 슬라이스’(Slice plate)를 눌러요.
  2. ‘플레이트 출력’(Print plate) 버튼 옆 ▼를 누르고 ‘플레이트 슬라이스 파일 내보내기’(Export plate sliced file)를 골라요. 위쪽 메뉴 파일 → 내보내기에도 있어요.
  3. 저장된 ○○○.gcode.3mf 파일을 여기에 올려요.

플레이트가 여러 개면 같은 메뉴의 ‘모든 슬라이스 파일 내보내기’로 저장한 뒤 플레이트를 골라 보세요. 계산기 시간은 슬라이스 화면의 총 시간(예열 포함)과 같아요.

  1. 오른쪽 위 ‘플레이트 슬라이스’(Slice plate)를 눌러요.
  2. ‘플레이트 출력’ 옆 ▼를 누르고 ‘G-code 파일 내보내기’(Export G-code file) 또는 ‘플레이트 슬라이스 파일 내보내기’를 골라요.
  3. 저장된 .gcode 또는 .gcode.3mf 파일을 여기에 올려요.

Creality Print, Elegoo Slicer 등 OrcaSlicer 기반 슬라이서도 메뉴가 거의 같아요.

  1. 오른쪽 아래 ‘지금 슬라이스’(Slice now)를 눌러요.
  2. ‘G-code 내보내기’(Export G-code)를 눌러 저장해요.
  3. 저장된 .gcode 파일을 여기에 올려요.

MK4·CORE One 등은 기본으로 바이너리 G-code(.bgcode)를 만드는데, 이건 아직 읽지 못해요. 프린터 설정 → 일반 → 펌웨어에서 ‘바이너리 G-code 지원’을 끄고 다시 내보내 주세요.

  1. 오른쪽 아래 ‘슬라이스’(Slice)를 눌러요.
  2. ‘디스크에 저장’(Save to Disk)을 눌러 .gcode로 저장해요.
  3. 저장된 파일을 여기에 올려요.

Cura는 무게(g)를 적지 않고 길이만 적어서, 1.75mm 필라멘트 기준으로 환산한 추정치가 들어가요. Cura 화면에 나온 g 값으로 고쳐 넣으면 더 정확해요.

메뉴 이름은 슬라이서 버전·언어 설정에 따라 조금 다를 수 있어요.

      판매 전 체크리스트 ⚠️
      • 모델 라이선스 — 남이 만든 모델이라면 라이선스를 꼭 확인하세요. CC BY-NC 계열과 MakerWorld 기본 라이선스(Standard Digital File License) 모델은 출력물을 팔 수 없어요. CC BY·CC BY-SA, 상업 라이선스를 허용한 모델, 직접 만든 모델은 판매할 수 있어요. 판매 전에 모델 페이지 라이선스를 캡처해 두면 좋아요.
      • 어린이제품 KC 인증 — 만 13세 이하 어린이가 쓸 수 있는 장난감·문구 등은 개인 판매라도 KC 인증 대상이 될 수 있고, 위반 시 처벌이 무거워요.
      • 통신판매업 신고 — 직전 연도 거래 50회 미만이거나 간이과세자면 신고가 면제돼요. 다만 오픈마켓은 입점할 때 신고증을 요구할 수 있어요.
      • 세금 — 꾸준히 판매하면 사업자등록과 부가세·소득세 신고가 필요할 수 있어요. 이 계산기의 판매가에는 세금이 들어 있지 않아요.

      법률 자문이 아닌 일반 안내예요. 정확한 판단은 국가기술표준원(어린이제품), 관할 시·군·구청(통신판매업), 세무서에 확인하세요. 수수료율도 판매자센터에서 최종 확인하세요.

        계산 방법

        • 필라멘트비 = 사용량(g) × 스풀 가격 ÷ 스풀 무게
        • 전기료 = 출력 시간 × 소비전력(kW) × 전기 단가 — 소비전력은 기종·재료별 출력 중 평균값
        • 감가상각 = 출력 시간 × 프린터 가격 ÷ 예상 수명
        • 실패 대비 = 실패율 r 일 때 성공 한 번에 평균 1 ÷ (1 − r)번 출력 → 합계 ÷ (1 − r)
